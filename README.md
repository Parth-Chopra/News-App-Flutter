# 📰 Cross-Platform News Reader Application

## 🌟 Project Overview

This is a modern, feature-rich **Cross-Platform News Application** developed using the Flutter framework. It provides users with a clean, responsive interface to access categorized news content instantly, designed for deployment on both **Android and iOS** devices.

The primary focus of this project was to implement efficient **State Management** and optimize application performance for a smooth user experience, achieving a **15% reduction in load times**.

## 🚀 Key Features

* **No-Login Access:** Users can immediately access all content without mandatory registration, maximizing accessibility and speed of use.
* **Categorized News Feeds:** News articles are dynamically categorized (e.g., Technology, Sports, World).
* **Short and Full-Length Reading:** Provides summary views for quick browsing and detailed full-length article views.
* **Responsive UI:** Designed with the Flutter framework for a consistent and responsive experience across various screen sizes.
* **Performance:** Implemented optimization techniques leading to a **15% reduction in application load times**.

## 💻 Tech Stack & Tools

| Category | Technology/Tool | Purpose |
| :--- | :--- | :--- |
| **Framework** | **Flutter** (Dart) | Cross-platform UI development. |
| **State Management** | **Provider** Package | Efficient and scalable data handling and UI updates. |
| **Data Source** | NewsAPI | Fetching real-time news data. | API Endpoint: v2/top-headlines

| **IDE** | Android Studio | Development Environment. |

## ⚙️ How to Run Locally

Follow these steps to get a local copy up and running:

1.  **Prerequisites:** Ensure you have the Flutter SDK and a working environment (Android Studio/VS Code) installed.
2.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Parth-Chopra/News-App-Flutter.git](https://github.com/Parth-Chopra/News-App-Flutter.git)
    ```
3.  **Navigate to the project directory:**
    ```bash
    cd News-App-Flutter
    ```
4.  **Install dependencies:**
    ```bash
    flutter pub get
    ```
5.  **Run the application:**
    ```bash
    flutter run
    ```
    *(Ensure a connected device or active emulator/simulator is running.)*
